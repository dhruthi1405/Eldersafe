# ElderCare v2

This folder contains the main production application.

## Contents

- `backend/` - FastAPI service for video processing and alerts
- `frontend/` - React dashboard
- `database/` - PostgreSQL schema and migrations
- `docker-compose.yml` - Local orchestration for the app stack

## Start Here

Use `docker-compose up --build` from this folder for the full app, or open the backend and frontend folders for manual setup.
