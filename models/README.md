# Models

Trained PyTorch models and training scripts live here.

## Files

- `binary_fall_best.pth` - binary fall detection model
- `activity_best.pth` - activity recognition model
- `train.py` - training entry point
- `binary_fall_train.py` - fall model training
- `activity_train.py` - activity model training

## Notes

Large checkpoint files are stored directly in the repo only when needed for demos or reproducibility.
